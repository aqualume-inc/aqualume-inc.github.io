# Aqualume
A product by Ebonlight Systems.

## GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root). Enable HTTPS. Expected URL: https://aqualume-inc.github.io/ after Pages is enabled and deployment succeeds.

## Home screen
iPhone: Safari → Share → Add to Home Screen. Android: use browser install menu or in-app installation button. Installation support varies; PNG Apple touch icons can be added for broader icon compatibility.

## Offline
App shell is cached after first online load. Leaflet resources are cached as used. Save water-point records explicitly; background map, geocoding and routing require internet. No prohibited bulk tile downloading. Saved data may be stale and is not a water-quality guarantee.

## Privacy and release checklist
GPS is permission-based. Bounds and place searches go to external map/data providers. Saved spots remain in local storage. Add legal operator contact/imprint and complete privacy information before public product release. Test mobile Safari/Chrome installation, GPS, permission denial, offline reopening, and map-service errors. Shared reports, marker clustering, and downloadable offline basemaps are not included in this release.
